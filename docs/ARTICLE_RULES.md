# 記事作成ルール・テンプレート（`docs/ARTICLE_RULES.md`）

このドキュメントは、**今後の「記事追加用の別会話」で AI と一緒に新しい記事を作成する際に毎回参照するための公式ルールブック**です。
本リポジトリでは **「1テーマ ＝ 1 Markdown ファイル」** を `src/content/articles/` 配下に追加するだけで、トップページの一覧・全文検索・2軸絞り込み・記事詳細ページ・左サイド目次・著者-年方式の参考文献欄が自動生成されます。

---

## 1. 科学的妥当性・倫理・品質の厳守ルール（最重要）

記事の作成・更新時は、以下の5原則を例外なく厳守してください。

1. **根拠と引用（著者-年方式：`(名前, 年)` 形式）**
   - すべての疫学数値、病態記述、神経画像所見、カットオフ値、診断精度、ガイドライン推奨には、提供された一次文献（査読付き原著論文、システマティックレビュー、学会公式診療ガイドライン等）を **著者-年方式** で紐づけること。
   - **本文中の引用表記**は数字（`[1]`）ではなく、以下のように **`(名前, 年)`** で記載すること：
     - 著者1名：`(Smith, 2023)`
     - 著者2名：`(Davis & Allen, 2013)`
     - 著者3名以上：`(Cannon et al., 2017)`
     - 同一筆頭著者・同年が複数ある場合：`(Kewcharoen et al., 2019a)` / `(Kewcharoen et al., 2019b)`
     - 複数文献の同時引用（セミコロン区切り）：`(Cannon et al., 2017; Yap et al., 2022)`
   - フロントマターの `references` 配列に各文献の **`citeKey`**（例：`"Cannon et al., 2017"`）を設定し、本文中の表記と **完全一致** させること（サイト側で自動的に参考文献欄へのクリック可能なジャンプ リンクに変換され、参考文献リストはアルファベット順で表示されます）。
2. **不確定情報・ハルシネーションの禁止**
   - ユーザーから提供された一次文献・確認済みメモに含まれない数値、カットオフ値、ハザード比、ガイドライン年、論文書誌情報を **AI の記憶だけで補完・創作しないこと**。
   - 情報が不足している項目は推測で書かず、本文中に `[要一次文献確認]` と明記するか（サイト上で目立つバッジ表示になります）、テーマに不要なセクションであれば省略すること。
3. **事実と考察の分離**
   - 先行研究・ガイドラインで確立された知見（セクション 2〜6）と、臨床・作業療法（OT）への示唆および今後の検証課題（セクション 7）を明確に区別すること。
4. **プライバシー・著作権の厳守**
   - 患者の個人情報や未匿名化の臨床データは一切含めないこと。
   - 論文の図表・画像・長文原文や、著作権のある評価尺度の設問内容そのものは無断転載せず、構造化した要約と一次文献リンク（PubMed / DOI）で表現すること。
5. **トーンと可読性**
   - 論文の Introduction / Discussion で参照できる学術的精度を保ちつつ、スマートフォンでも読みやすい簡潔な箇条書き・Markdown テーブルを活用すること。

## 2. ファイル配置と命名規則

- **保存先ディレクトリ**：`src/content/articles/`
- **ファイル名**：半角英小文字とハイフン（kebab-case）の `.md` ファイル（これがそのまま記事 URL `/articles/<ファイル名>` になります）
  - 例：`hf-cognitive-impairment.md` → `/articles/hf-cognitive-impairment`
  - 例：`icu-pics-cognitive-early-rehab-ot.md` → `/articles/icu-pics-cognitive-early-rehab-ot`

---

## 3. フロントマター（YAML メタ情報）仕様

Markdown ファイルの先頭（`---` で囲む部分）に以下のメタ情報を記述します。必須項目が欠けたり型が合わない場合、ビルド時に自動チェックでエラーが出る仕組みになっています。

```yaml
---
title: "記事タイトル（日本語）"                        # 必須
titleEn: "Article Title in English"                   # 任意
summary: "トップページ一覧とSEOに表示する要約（80〜180文字目安）"  # 必須
categories:                                           # 必須（1つ以上）
  - "循環器・心不全"
  - "認知機能"
tags:                                                 # 必須（1つ以上、# は付けない）
  - "疫学・病態"
  - "神経画像"
  - "先行研究"
  - "ガイドライン・基準"
  - "評価指標"
phase:                                                # 任意（対象フェーズ）
  - "急性非代償性（ADHF）"
  - "慢性安定期"
updatedAt: "2026-11-26"                               # 必須（YYYY-MM-DD 形式）
guidelineYear: "JCS/JHFS 2025, ESC 2021 等"           # 任意
evidenceTypes:                                        # 任意（参照エビデンス種別）
  - "診療ガイドライン"
  - "システマティックレビュー"
  - "コホート研究"
status: "published"                                   # 任意（"published" または "template"）
references:                                           # 参考文献（著者-年方式）
  - id: 1
    citeKey: "Cannon et al., 2017"                    # 必須推奨：本文中の (Cannon et al., 2017) と完全一致させる
    citation: "Cannon JA, Moffitt P, Perez-Moreno AC, et al. Cognitive Impairment and Heart Failure: Systematic Review and Meta-Analysis. J Card Fail. 2017;23(6):464–475."
    doi: "10.1016/j.cardfail.2017.04.007"             # 任意（https://doi.org/ は不要）
    pmid: "28433667"                                  # 任意（数字のみ）
    url: ""                                           # 任意（DOI/PMIDがない公式ガイドライン等）
    note: ""                                          # 任意（未確認時のみ "要一次文献確認" 等）
---
```

### 標準の領域カテゴリ（`categories`）
`src/config/site.ts` で定義されている標準カテゴリです（必要に応じて新しいカテゴリを追加しても一覧の絞り込みに自動反映されます）。
- `循環器・心不全`
- `ICU・集中治療`
- `呼吸器`
- `認知機能`
- `評価法・研究手法`

### 標準の記事タイプタグ（`tags`）
`#` を付けずに記述してください（画面上で自動的に `#` が表示されます）。
- `疫学・病態`
- `神経画像`
- `先行研究`
- `ガイドライン・基準`
- `評価指標`

## 4. 本文の標準見出し構成（モジュラー型）

テーマに応じて不要なセクション（例：神経画像所見や評価指標が該当しないテーマ）は省略可能です。見出し番号（`## 1. ...`）を連番で振ると、末尾の「参考文献（References）」セクションにも次の番号が自動で振られます。

- `## 1. 要点（Key Summary）`（3点程度。`<div class="summary-box">...</div>` で囲むと強調枠になります）
- `## 2. 疫学・臨床的背景`
- `## 3. 病態・生理学的メカニズム`（必要に応じて `<div class="flow-diagram">...</div>` を利用可）
- `## 4. 神経画像所見（Neuroimaging Findings）`（該当時）
- `## 5. 評価指標・スクリーニングの比較`（該当時。Markdown の表はスマホで自動横スクロール対応）
- `## 6. 主要エビデンス・ガイドライン`（先行研究サマリー表・介入エビデンスを含む）
- `## 7. 臨床・作業療法（OT）への示唆と今後の課題`（`<div class="clinical-split">...</div>` で「臨床的示唆」と「今後の課題」を2列整理可）
- **参考文献セクションは本文中に書かず、フロントマターの `references` に記述してください**（記事末尾にアルファベット順・著者-年バッジ・PubMed/DOIリンク・ワンクリック引用コピーボタン付きで自動表示されます）。

---

## 5. 特殊記法（本サイト専用の自動変換機能）

- 本文中の `(Cannon et al., 2017)` や `(Cannon et al., 2017; Yap et al., 2022)` など、フロントマターの `citeKey` と一致する表記は、自動的に参考文献リストの該当文献へジャンプするリンクに変換されます。
- `[要一次文献確認]` と書くと、黄色系の「要一次文献確認」バッジに自動変換されます。
- Markdown の表（`| 列1 | 列2 |`）は、すべて自動的に横スクロール可能な枠で囲まれ、スマートフォンでも崩れません。

## 6. 記事追加用 AI プロンプト（別会話でコピペして使用）

新しい記事を追加したいときは、別の会話を開いて以下をそのまま貼り付け、【対象テーマ】と【一次文献・メモ】を埋めて依頼してください。

```markdown
リポジトリ内の `docs/ARTICLE_RULES.md` のルールおよびフロントマター仕様に厳密に従い、以下の【一次文献・メモ】をもとに公開リファレンスサイト用の記事（Markdown形式）を作成してください。

# 厳守事項
1. すべての疫学数値・病態記述・神経画像所見・評価基準・推奨には、下記に提供した一次文献を **著者-年方式（本文中は `(名前, 年)` 例：`(Cannon et al., 2017)`、複数文献は `(A et al., 2020; B et al., 2022)`）** で紐づけること。数字による `[1]` 形式は使用しないこと。
2. 書誌情報はフロントマターの `references` に `id`・`citeKey`（本文中表記と完全一致）・`citation`・`doi`・`pmid` で記載すること。同一筆頭著者・同年が複数ある場合は `2019a` / `2019b` で区別すること。
3. 提供された一次文献・確認済みメモにない数値や論文を AI の記憶だけで補完・創作しないこと。不足箇所は推測で書かず `[要一次文献確認]` と明記するか、不要セクションは省略すること。
4. 確立されたエビデンスと、臨床・作業療法（OT）への示唆・今後の検証課題を明確に区別すること。
5. 個人情報・未匿名化データは一切含めず、論文原文や図表の無断転載はしないこと。
6. 保存先ファイル名案（`src/content/articles/<slug>.md`）も併せて提示すること。

---
【対象テーマ】：ここにテーマ名を入力
【一次文献・メモ】：ここに論文の書誌情報・DOI・PMID・要旨・調べたメモを貼り付け
```

## 7. 公開前チェックリスト

記事ファイルを追加・更新したら、公開前に以下を確認してください。

- [ ] フロントマターの必須項目（`title`, `summary`, `categories`, `tags`, `updatedAt`）が揃っている
- [ ] `updatedAt` が `"YYYY-MM-DD"` 形式になっている
- [ ] 本文中のすべての引用が `(名前, 年)` 形式で書かれ、フロントマターの `references[].citeKey` と完全一致している（数字 `[1]` が残っていない）
- [ ] 未検証の箇所が残っている場合、`[要一次文献確認]` が明記され、必要に応じ `status: "template"` になっている
- [ ] 架空の論文・記憶補完の数値・個人情報が一切含まれていない
- [ ] `npm run build` がエラーなく完了する
